# PractoForAnimals

Multi-module web application with three integrated modules.

## Modules
- Practo for Animals - Animal care discovery and appointment requests.
- AI Education - Course listings and student enquiries.
- AI Content Creator - Template-based carousel generation and exports.

## Technology Stack
- HTML, CSS, JavaScript
- Python, FastAPI, SQLite
- Uvicorn, Python-PPTX, ReportLab

## Run Locally
1. Install dependencies: python -m pip install -r requirements.txt
2. Start backend: python -m uvicorn backend.main:app --reload
3. Open http://127.0.0.1:8000/
